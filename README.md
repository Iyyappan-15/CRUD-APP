🎓 Student Management System (CRUD App)

A simple Student Management System built using HTML, CSS (Bootstrap), JavaScript, Node.js, Express, and MongoDB.
It allows you to Add, View, Update, and Delete student records easily — all from a clean and user-friendly interface.

🚀 Features :

🧾 Add new students

📋 View all student details

✏️ Edit student records

❌ Delete student records

🔢 Automatically arranged serial numbers

🌗 Light/Dark mode toggle

🖼️ Custom favicon for a professional look

🛠️ Technologies Used :

Frontend: HTML, CSS (Bootstrap), JavaScript

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)

⚙️ Installation & Setup :

Follow these simple steps to run the project locally:

Clone the repository:

git clone https://github.com/yourusername/Student-Management-System.git


Navigate to the project folder:

cd Student-Management-System


Install the required dependencies:

npm install


Create a .env file in the root folder and add your MongoDB connection string:

MONGO_URI=your_mongodb_connection_string
PORT=5000


Run the server:

node server.js


Open your browser and go to:

http://localhost:5000
